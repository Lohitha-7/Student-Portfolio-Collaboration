## Three Git Commands I Learned

1. `git status` — Shows the state of the working directory and staging area.
2. `git add <file>` — Stages changes for the next commit.
3. `git commit -m "message"` — Records staged changes in the local repository.

## Purpose of GitHub

GitHub hosts Git repositories online and supports collaboration, code review, and project sharing.

## One Benefit of Branches

Branches let developers work on changes separately without immediately changing the main branch.
